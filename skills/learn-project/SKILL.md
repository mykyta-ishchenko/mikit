# Learn Project

Read and internalize the project knowledge base before starting work.

## Required Reading

1. **The repository tree** — print it two or three levels deep, ignoring what git ignores, to see the layout before reading anything else
2. **`CLAUDE.md`** — rules, workflow, communication style, and every file it references
3. **`README.md`** and **`CONTRIBUTING.md`** if present — tech stack, layout, setup, conventions
4. **The project's task runner file** — Taskfile, Makefile, justfile, `package.json` scripts, whatever the repo uses. List the available commands.

## Documentation

Read every `.md` file under the project's documentation directory recursively, `docs/` or wherever `CLAUDE.md` and `README.md` point. Skip plans, specs, and decision archives unless the current task needs them.

## After Reading

Confirm you have full context and are ready to work.
